Nesse projeto utilizei uma planilha ficticia de dados no excel de uma rede de farmacia, onde para analisar e fazer os dahboard usei o **Power BI**.

## **Competências e Aprendizados Adquiridos na realizaçao desse projeto:**

**Extração e Tratamento de Dados (ETL)**
Integração de planilhas do Excel no Power BI,
Limpeza de dados, ajuste de colunas e criação de etapas automatizadas no Power Query.

**Modelagem de Dados Relacional**
Construção de relacionamentos eficientes conectando as tabelas de Vendas e Produtos através do código do produto,
Garantia da integridade dos dados para cálculos e cruzamentos precisos entre as informações.

**Análise de Indicadores Chave de Desempenho (KPIs)**
Definição e exibição de métricas essenciais como Faturamento Total e volume de vendas,
Mapeamento de tendências temporais com gráficos de linhas cobrindo o histórico comercial de 2021 a 2023.

**Design Visual e Interatividade**
Organização do layout focada na experiência de quem vai analisar os dados, cores limpas, textos legíveis e gráficos,
Aplicação de filtros interativos para permitir a análise detalhada de produtos específicos, como fraldas em tempo real.

**Conclusão:**
O desenvolvimento deste DASHBOARD demonstrou como a combinação entre organização de dados e visuais interativos transforma uma planilha comum em uma ferramenta poderosa. Isso facilita o acompanhamento de metas, acelera a tomada de decisões e revela padrões de vendas fundamentais para o crescimento de uma rede de farmácias. Mostrando de forma clara o quanto essa interatividade facilita na Analise de Dados.
